# Save5Hours — organization profile

This repository holds the public profile and the default community health files for the
[Save5Hours](https://github.com/Save5Hours) GitHub organization.

## What lives here

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The public README rendered on the organization page |
| `assets/` | Brand assets (logo lockups, mark, banners) |
| `SECURITY.md` | Default security policy for every org repository |
| `CODE_OF_CONDUCT.md` | Default code of conduct for every org repository |
| `.github/ISSUE_TEMPLATE/` | Default issue forms inherited by repos without their own |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |

Files in this repository are inherited by any Save5Hours repository that does not define
its own version of them.

## Brand assets

| File | Use |
| --- | --- |
| `assets/logo-light.png` | Full lockup, transparent background — light surfaces |
| `assets/logo-dark.png` | Full lockup, transparent background — dark surfaces |
| `assets/mark-light.png` | Icon only — light surfaces |
| `assets/mark-dark.png` | Icon only — dark surfaces |
| `assets/banner-light.png` | Wide banner — light surfaces |
| `assets/banner-dark.png` | Wide banner — dark surfaces |

Primary orange: `#F06000` · Ink: `#0B0B0D`

## Editing the public profile

Changes to `profile/README.md` on the `main` branch appear on the organization page
immediately after merge. Keep image references as absolute `raw.githubusercontent.com`
URLs so they resolve correctly on the organization profile.
